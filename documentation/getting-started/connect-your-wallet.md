# Connect Your Wallet

Splitty uses wallet authentication to identify the account that will fund and authorize payments.

## Connect

1. Open Splitty.
2. Select **Get started** or **Connect**.
3. Complete the wallet or email authentication flow.
4. Confirm that the connected account is the one you want to use.

The app displays the connected address in the navigation bar.

## Network

Split execution is designed for Arc. If the wallet is connected to the wrong network, Splitty prompts you to switch before sending.

## Before your first split

Make sure the wallet has enough balance for the selected token and that any required USDC Gateway liquidity has been funded if you plan to use Gateway funding.
